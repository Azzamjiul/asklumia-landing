# AskLumia Landing Page

Pure static landing page for [AskLumia](https://asklumia.ai/hub) — no build step, no dependencies. Deploy-ready for Netlify.

## Structure

- `index.html` — single-page markup
- `styles.css` — all styles (vanilla CSS, responsive)
- `script.js` — mobile nav + scroll reveal (vanilla JS)
- `netlify.toml` — Netlify config (publish: `.`, basic headers)

## Deploy

Drag & drop this folder to Netlify, or connect the repo:

- **Build command:** (none)
- **Publish directory:** `.`

## Edit

All content lives in `index.html` — copy, sections, and links are plain HTML. Colors and spacing are CSS variables at the top of `styles.css`.
